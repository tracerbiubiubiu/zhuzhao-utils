# zhuzhao-utils

zhuzhao生态的Go通用工具库：签名验签、双令牌、错误码/响应、日志、PostgreSQL、Redis及纯校验工具。只收无业务数据依赖的工具；各包目录和Go doc继续作为包级入口。

从 [文档导航](docs/README.md) 开始，查看 [接入用法](docs/guides/usage.md)、[公共包/API](docs/api/README.md)、[AK/SK边界](docs/api/aksk.md)、[发布与pin](docs/ops/releases.md) 或 [开发门禁](docs/guides/development.md)。

v0.4.3已发布；Streaming/Reader及后续审计修复是否可用须核精确版本，不代表新tag已发布。

```sh
go get github.com/tracerbiubiubiu/zhuzhao-utils@v0.4.3
```
